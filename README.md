Nome do Projeto: Bookando
Grupo: Karleane Pacheco da Silva, Maria Fernanda Correa e Vinicius Gomes de Lima

SOBRE O PROJETO
É um site de avaliação de livros, onde o usuário:
- Se cadastra
- Faz login no site
- Passei pela biblioteca de livros disponiveis
- Faz avaliações dos livros

Ele pode customizar ser perfil com uma foto e um descrição, que usa da extensão Quill para aumentar a personalização.
Caso ele não tenha encontrado o livro que queria fazer a avaliação, ele pode solicitar a nossa equipe o livro atráves da aba: Solicitações!
